Technology and Programming Language Requirements
The project can be implemented using any programming language. The application form is flexible – implementation as a console application, desktop with GUI, web application, or mobile application is acceptable. Unity, Godot, etc., can be used. You have complete freedom in choosing technologies, programming environment, and libraries. It is important to adhere to the principles of code readability, modularity, and appropriate documentation, as well as documenting project progress on Trello.
